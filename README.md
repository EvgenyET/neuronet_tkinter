# neuronet_tkinter

Настольное приложение для просмотра истории Bitcoin на холсте Tkinter Canvas. Свечи, линии, оси и курсор рисуются средствами интерфейса. Пользователь может менять представление данных, масштаб и положение графика.

**Python-портфолио Евгения Толмачева** · Python · CustomTkinter · Tkinter Canvas · pandas

![Интерфейс neuronet_tkinter](docs/preview.webp)

## Возможности

- Переключает свечной и линейный вид графика.
- Поддерживает обычную и логарифмическую шкалу цены.
- Масштабирует график колёсиком мыши и перемещает его вместе с осями при перетаскивании.
- Выводит перекрестие курсора и цену, перестраивает область графика при изменении размеров окна.

## Как устроен проект

### Окно и взаимодействие

[`neuronet_tkinter.py`](neuronet_tkinter.py)

Классы App и MyFrame собирают интерфейс, обрабатывают события мыши и синхронизируют холсты цены, дат и графика.

### Обычная шкала

[`change_data.py`](change_data.py), [`change_data_line.py`](change_data_line.py)

Подготавливают данные и координаты для свечного и линейного отображения.

### Логарифмическая шкала

[`change_data_log.py`](change_data_log.py), [`change_data_log_line.py`](change_data_log_line.py)

Преобразуют значения цены и рисуют те же виды графика в логарифмическом масштабе.

## Технологии и их роль

- **CustomTkinter**: Окно, панели, переключатели режима и оформление приложения.
- **Tkinter Canvas**: Собственная отрисовка графика и обработка масштабирования и перемещения.
- **pandas**: Чтение и подготовка сохранённых временных рядов.

## С чего начать просмотр кода

В MyFrame интересны расчёт координат, zoom и on_drag. Отдельные change_data-модули показывают различия четырёх режимов отрисовки.

## Подготовка и запуск

Создайте отдельное окружение и установите исходные зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Нужен dataframe.pkl. Несмотря на историческое название, основной предмет этой версии - интерфейс и графики, а не обучение нейросети.

После подготовки настроек и необходимых данных основная точка входа:

```powershell
python neuronet_tkinter.py
```

`requirements.txt` сохранён из проекта. Это снимок окружения, а не гарантия совместимости с новейшей версией Python. Для старых проектов могут потребоваться соответствующая версия Python и настройка системных компонентов.
